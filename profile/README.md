<h1 align="center">DonaBe</h1>
<h3 align="center">Conectando doadores a instituições de caridade perto de você</h3>

<p align="center">
Esta organização foi criada com o objetivo de gerenciar o desenvolvimento de uma plataforma WEB que facilita a vida de quem quer doar, ajudando doadores a encontrar instituições de caridade na sua região.
</p>

<p align="center">
O projeto reúne, em um repositório central, a aplicação WEB, o backend compartilhado e a infraestrutura necessária para executá-los em um monorepo.
</p>
